# RedBox 📦🔴

> **Everything you need. One RedBox.**

RedBox is a modern, offline-first Android toolbox for school, study, and everyday life.

## v0.9.0

RedBox v0.9 focuses on a cleaner, faster dashboard experience:

- 🧮 **Calculator** — fast arithmetic with decimals and divide-by-zero handling
- ⏱️ **Focus Timer** — simple Pomodoro-style focus sessions
- 📊 **GPA Calculator** — weighted GPA from courses, grades, and credits
- 📝 **Notes** — create, edit, delete, search, pin, and offline persistence
- 🔄 **Unit Converter** — length, weight, temperature, and speed
- 🧰 **More Tools** — percentage, discount, number-base, age, and countdown utilities
- ⭐ **Favorites** — pin the tools you use most
- 🕘 **Recent Tools** — quick access to recently opened tools
- 🔎 **Tool Search** — instantly filter the toolbox
- ✨ **Polished dashboard** — adaptive grid, grouped sections, and smooth page transitions
- 🌙 **Light/Dark Theme** — persistent theme preference
- ℹ️ **About RedBox** — product and version information

## Stack

- Kotlin
- Jetpack Compose
- Material 3
- MVVM-ready architecture
- Android SDK 26+
