# RedBox 📦🔴

> **Everything you need. One RedBox.**

RedBox is a modern, offline-first Android toolbox for school, study, and everyday life.

## v0.1.0

The first foundation release includes a polished Jetpack Compose dashboard with the initial tool catalog:

- 🧮 Calculator
- ⏱️ Focus Timer
- 📊 GPA Calculator
- 📝 Notes
- 🔄 Unit Converter
- 🧰 More Tools placeholder

## Stack

- Kotlin
- Jetpack Compose
- Material 3
- MVVM-ready architecture
- Android SDK 26+

## Product identity

**RedBox** is a Redlighte product. The visual language is modern, minimal, friendly, and red-first, with the goal of making useful tools feel effortless.
